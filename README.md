# Modelo de Portfólio Pessoal

Modelo simples e responsivo feito com HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — conteúdo e seções do portfólio.
- `css/style.css` — cores, tipografia, layout e responsividade.
- `js/script.js` — menu mobile e ano automático no rodapé.
- `assets/images/` — coloque aqui sua foto e imagens dos projetos.

## Como personalizar

1. Abra `index.html` em um editor de código.
2. Substitua os textos entre colchetes, como `[SEU NOME]`, pelos seus dados.
3. Atualize e-mail, LinkedIn, GitHub e links dos projetos.
4. Coloque sua foto em `assets/images/minha-foto.jpg` (ou ajuste o caminho no HTML).
5. Edite as cores no início de `css/style.css`, se desejar.

## Como visualizar

Abra o arquivo `index.html` no navegador. Para publicar, envie os arquivos para seu repositório GitHub e conecte o projeto à Vercel ou GitHub Pages.
